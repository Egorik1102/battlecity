## Рабочий процесс и договоренности
*   **Каналы связи:** Telegram-чат для быстрых вопросов, созвон в Discord раз в неделю (по средам).
*   **Процесс:** Git Flow. Ветки `main` и `develop` защищены. Вся работа через Pull Request (PR).
*   **Код-ревью:** Каждый PR проверяется тимлидом или другим участником перед мержем в `develop`.
*   **Стиль кода:** C++17, CamelCase для классов (например, `class Tank`), camelCase для переменных (например, `int health`).
*   **Сроки:** Проект сдается 15 декабря 2026 года. Чекпоинты каждую неделю.

## MVP (Minimum Viable Product) — до 01.12
*   Движение танка игрока (WASD).
*   Стрельба (ЛКМ).
*   Карта со стенами.
*   Враги (статичные или простой AI).
*   Подсчет здоровья и очков (HUD).
