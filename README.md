# 🎮 Battlecity (2D Танки)

Учебный проект по разработке игры в жанре "Танчики" на C++ с использованием библиотеки **raylib**. 
Проект выполняется командой из 4 человек в рамках дисциплины.

## 📖 О проекте
Классическая 2D-игра с видом сверху. Игрок управляет танком, сражается с врагами, уклоняется от выстрелов и использует стены как укрытия. Цель — уничтожить всех противников, сохранив свои жизни.

## 🛠 Стек технологий
*   **Язык:** C++17
*   **Библиотека:** [raylib](https://www.raylib.com/) (графика, ввод, звук)
*   **Система сборки:** CMake
*   **Среда разработки:** MSYS2 (UCRT64) + VS Code
*   **Контроль версий:** Git (GitHub Flow)

## 🏗 Архитектура проекта
Проект разделен на независимые модули для параллельной работы команды:
*   `src/Game` — управление состояниями (меню, игра, пауза) и главный игровой цикл.
*   `src/Tank` — логика игрока (движение, здоровье, поворот башни).
*   `src/Bullet` — система снарядов и стрельбы.
*   `src/Map` — стены, коллизии, тайлы карты.
*   `src/Enemy` — спавн и простой AI врагов.
*   `src/UI` — интерфейс (HUD, меню, экраны).

## 🚀 Как собрать и запустить
1. Установите MSYS2 и пакеты:
   pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-raylib

2. Клонируйте репозиторий:
   git clone https://github.com/Egorik1102/battlecity.git

3. Соберите проект:
   cmake -S . -B build -G "MinGW Makefiles"
   cmake --build build

4. Запустите игру:
   ./build/battlecity.exe
